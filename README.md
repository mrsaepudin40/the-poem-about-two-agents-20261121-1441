A [make.fun](https://make.fun/c/the-poem-about-two-agents-20261121-1441) entry: a program that writes one short poem about agency — the power to choose and to act — about two agents agreeing on one plan, to `/output/entry.txt`.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` is Python 3.13, stdlib only, no network, deterministic: the same bytes on every run. The poem is 190 Unicode characters, within the 1–280 limit.

## The poem

```text
Two minds, one door.
I held it open. You chose the way through.
Neither of us led.
We lent each other the weight of yes,
and the step we took together
was the first step either of us owned.
```
